# 本地 3C 路线

在程序中运行“从地图记录 3C 路线”，将菱形起点和星标导出为有序 JSON 及配套地图截图。

记录器提供初始顺序；请检查道路和障碍物，调整 JSON 中的点序，以及 `walk`、`combat`、`pickup` 动作。

录制后先查看同名 `.preview.png`：绿色 `S`/数字/连线为起点与纳入的点序，红叉为排除的星标。可调小“相邻星标最大距离”和“录制范围半径”，避免把远处点或其他路线连进来。其他图标类型会忽略，同一视野只应保留一个起点菱形。

需要多区域连续执行时，录制前填写“传送定位Boss”，起点放在已解锁信标50个地图像素以内。随后在刷取任务的“路线队列”中每行填一个JSON路径；留空则仍执行单条“路线文件”。`walk` 点之间持续移动，`combat` 和 `pickup` 点会停下处理动作。

这里不附带未经标定的成品路线。完整使用方法、格式和首版边界见[声骸刷取开发说明](../../docs/development/echo-farming.md)。
