# 本地 3C 路线

在程序中运行“从地图记录 3C 路线”，将路线星标导出为有序 JSON 及配套地图截图。默认 `Nearest Beacon` 无需菱形：把目标星标组放在中央附近，记录器选取中央星标组并自动选择最近的可见信标作为入口。`Star Selection` 默认 `Connected Group`，根据相邻间距和录制半径排除远路线；显式 `All Visible Stars` 会纳入中央录制区域内所有已检星标、忽略距离限制，使用时要把其他路线移出该区域。最近一次未标注梦枢图中三颗星均已检出，但默认连通分组因相邻间距只保留一颗，另外两颗被排除。信标到首个星标只受录制半径限制，不受星标间最大距离限制，所以首段可能跨过障碍；请检查预览，必要时补途经星。该方式至少需要一个星标；`Diamond` 方式仍要求至少两个星标。

记录器提供初始顺序；请检查道路和障碍物，调整 JSON 中的点序，以及 `walk`、`combat`、`pickup` 动作。

录制后先查看同名 `.preview.png`：绿色 `S`/数字/连线为选定入口与纳入的星标顺序，红叉为排除的星标。可调小“相邻星标最大距离”和“录制范围半径”，避免把远处点或其他路线连进来。其他图标类型会忽略。默认开启“Capture Teleport Overview”：读取星标后逐步缩小地图，最多保存 6 张配准通过的 `.view-N.png`，主路线图和星标坐标保持不变。

录制时可选在 `Map Selection Path` 填地图菜单精确名称，一行一级、父级到子级；它只保存选择标签，不在录制中点菜单。执行前任务先回到大世界，再通过 OCR 唯一稳定匹配并逐级点击；后续仍须通过地图强配准、信标和传送按钮确认，以及落地后小地图起点确认。当前没有梦枢天罗菜单展开素材、不支持菜单滚动或自动推断地图身份，也不能声称覆盖任意地图任意地点；梦枢天罗等跨层路线本版不自动切层，`map_layer` 仅为预留字段。书签搜索限于已录制地图范围和同一地图层。可选填写旧版“Teleport Anchor”保留 Boss 图鉴方式；旧路线仍兼容。随后可在“路线队列”每行填一个 JSON 路径；留空则执行单条“路线文件”。`walk` 点之间持续移动，`combat` 和 `pickup` 点会停下处理动作。

迁移路线时请一起保留 JSON、`.map.png`、`.preview.png` 和全部 `.view-N.png`。菜单 OCR 选择、自动缩放、视图搜索、信标及传送界面判断尚未通过完整实机验收，也不保证所有地图视野都能配准成功。这里不附带未经标定的成品路线。完整使用方法、格式和首版边界见[声骸刷取开发说明](../../docs/development/echo-farming.md)。
